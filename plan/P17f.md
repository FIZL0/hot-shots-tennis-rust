# P17f

- [x] **P17f — Animated court textures (MTA/UVA).** Drive court material colour/UV tracks (water, flags) per frame, as
  N1d4 does for faces.

Done: `hst_sim::court_anim` plays the hole model's `.UVA` (per material `@mtluva_<name>` or per node palette, offset
swapped for packets with header +0x58) and `.MTA` (material alpha), looping from the start. The app splits meshes per
UV track and writes `GsUniform::uv_offset`/alpha each 60 Hz tick. Court 10's RAM offsets are matched bit-exact
(research/journal/2026-10-07-p17-court-rendering/3-ANIMATED-TEXTURES-FINAL.md). Left: court `.MOR` (resort splash, tree
`.mor`), `.TAF` texture animation, structure `.uva` (no loader found).
