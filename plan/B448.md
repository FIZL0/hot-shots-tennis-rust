# B448 — Mods and Settings in the roster look (user 2026-10-15, top priority)

Concept: https://claude.ai/artifact/7p2k1xtBSHZJwBzc9NrybH ("Menus in the Roster Look", 1280×720 references: Mods Browse,
Installed, Upload; Settings). Like every menu it is ours to design and lays out at any aspect ratio, scaled uniformly.

Why: the roster (B368/B382, `roster.rs`) is the look the user wants. Mods (`mods_screen.rs`) still has pink grid paper, a
tab-flag title and a grey-purple filter rail; Upload is the old cream list; Settings has the tab-flag title and cream panels.

## Shared language (take values from `roster.rs`, don't re-pick them)

- Background `#0e1a2e` (no grid paper), plain white title "‹ Mods" / "‹ Settings".
- Each mod kind uses a roster seat colour set (ring / selected / column / well / tile / soft): Characters red, Courts green,
  Umpires blue, Texture packs gold. The kind tabs (L2/R2) are ring-bordered pills, the chosen one filled.
- Columns: 14px radius, 3px ring border, column fill, 10px padding. Pills in the well colour; the chosen one filled with ring.

## Mods (Browse, Installed, Upload, My uploads)

- **Left column**: header row (small tag STORE / THIS MACHINE / UPLOAD, big "Browse characters", status on the right); then
  the Show pills (Everything · Installed · Updates · My uploads · Saved) with "◂ Newest ▸" sort and one filter pill on the
  right. The filter rail goes: Game / Plays like / Hand become values the filter pill cycles (Select).
- Tile grid like the roster's: square tiles, a heading per game (name · count, rule under it; first in ring colour),
  selected tile in the selected colour with a 3px inset ring. Corner badge for state (Update gold, Installed green,
  New blue; on Upload: Uploaded, Uploading, Queued, Failed, Skipped), a ring-coloured progress bar on downloading tiles,
  6px scroll bar, soft footer line.
- **Right column** laid out like a roster player's column: big name, "by …" right; one info line in the soft colour:
  how many costumes (left) and which hand (right). **No costume switcher and no hand switcher** (user 2026-10-15): plain
  text, no L1/R1 or Select glyphs, not selectable. Then preview + 150px stack (gold play-style label over the pink stats
  card, grade colours as the roster), facts (game, version · size · plays like, verified line in green), and at the
  bottom a ring-coloured primary button plus two well-coloured secondary buttons.
- Installed: Remove asks inside the column (selected-colour box above the button: "Remove Allan? …", Remove / Cancel /
  Reload select). Upload: the rights rule in a well box above the button. My uploads is Installed with Take down.
- Courts, umpires and texture packs keep their own detail content from plan/B372.md § Kinds, in this frame.

## Settings

- Page tabs (Display · Graphics · Sound · Controls · Online & Mods) as ring pills between L1/R1; "Changes apply right away".
- Left column: page name + option count, option rows styled as tiles (selected one with the inset ring), value in a well
  pill "◂ Fullscreen ▸" (Off in the soft colour). Right column: the option's name, a one-line explanation, CHOICES rule,
  the choices as pills (current one filled).
