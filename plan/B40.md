# B40

Main menu, settings, controller assignment, simultaneous character select, match confirmation (`play/main_menu.rs`).

Done (B40a–d):
- **B40a** Main menu (Local / Online placeholder / Settings / Quit) in the original menus' disc art: walls, titles, the
  `word.tm2` font, the INPANE hand, `message0.dat` descriptions, SYS_SE00 move/confirm/back sounds.
- **B40b** Settings: widescreen, uncapped fps, upscaled textures, music, each on/off in `settings.txt` beside the disc
  image, passed to the match as `--4x3` / `--vsync` / `--no-upscale` / `--music`. Controls screen rebinds each
  action's key and pad button into `controls.txt`.
- **B40c** Local: singles/doubles, controller assignment (the host's device is 1P; other pads join with ✕, the match
  takes two humans, keyboard 1P only), then the character select with a cursor per player, costumes (L1/R1, Q/E),
  attribute cards (△) from the MENU overlay's grade table (`exe::Menu::grades`) and TParam's play style; a costume
  someone has readied on is blocked for the others; the host then picks the computer's players.
- **B40d** Confirm: court (11), sets 1/3/5, games 1–6, umpire (5); starts the match as a child process with the
  choices (`--chars --outfits --umpire --sets --games --pads`), the menu hidden until it ends. Match player order:
  singles 1P→0 2P→1, doubles 1P→0 2P→2 3P→1 4P→3.

Gaps (PLAN lines): B40e (1:1 layout/animation/ticker/BGM), B40f (in-process menu↔match), B40g (M7 cameras and the
original's other pre-match options), B40h (more than two humans, keyboard as its own player).
