# N1d4

- [x] **N1d4 — Faces.** `.MOR` morph and `.UVA` UV-animation files (`PCDATA/PCCG0.XB` MtGrl/pcNN, per motion, `_2`
  variants): format, which face plays with which motion (index + 0x1404 rule in the N1c journal), playback.

Done: `hst-data::mor` parses .MOR (width 1) and .UVA (width 4); `mdl` reads per-packet morph blocks (`Packet.morphs`, `Model.morph_names`, `skinned()` returns per-target model-space offsets). `hst-sim::face` has the game's sampler (`sample`, ramp from 0 before the first key, held after the last, cursor search) and `length`; tests/face.rs: 176 morph players / 470 weights bit-exact vs five RAM dumps, 460 MOR files parse, 1627 tracks bind, 36 don't (the game's exact-name strcmp drops them too). `character.rs`: Bevy morph targets per skinned part, face clock per motion (0x1c/0x1d keep the face). Not done (ponytail): UVA playback in the app (only gu_set win pose and co reactions use it; MTL has no texture names to map to), co faces from PCCG0 MtGrl, the +0x1404 team-reaction offset, key cursor restarts at 0 (≤1 ulp after a wrap). Morph delta semantics (entry += weight·delta, bone space) assumed, VU1 microcode not checked.
