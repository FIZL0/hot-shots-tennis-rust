# P9a — effect model player

- EFFCT.XB0: 100 files; `yumoto/impact_*`, `hatsuyama/efct`, `azuma/chara_eff` (character sets), `panel`, `prize`. All parse (hst-data tests/effects.rs).
- `.ANI` is hierarchical: header {tpf, roots}; per track {namelen, f32 length, pad}, name, rotation list, position list, u32 child count (16-padded); children follow depth first. Character ANIs are all roots, so the old flat reader only worked by luck. ani.rs: `Track.parent` replaces the never-used scale list.
- `.MTL` material names (extra bytes, NUL-terminated) carry the blend: default GS ALPHA 0x44 `(Cs−Cd)·As+Cd`, `@add` 0x48 `Cs·As+Cd`, `@sub` 0x42 `Cd−Cs·As` (tested after @add, so it wins); `@vert` ⇔ colour alpha 0x80. mtl.rs: `Material.name`, `Material::blend()`.
- Model animator (0x3b0 object): model clock +0x38 sampled / +0x3c time / +0x40 speed; channel 0 = MOR player, channel 3 = MTA player. MTA tracks bind to materials by exact name; each entry writes alpha into the material's colour slot (+0xc). Empty track → 1.0. Length = last tick of the bound tracks / tpf (face::length).
- Per frame: model clock, then MOR, then MTA, each a non-looping motion::Clock (sample at the clamped time, then +1). Start = reset to 0 **and** one frame in the same game frame (first live frame: sampled 0, time 1). It ends when MOR length ≤ sampled: values reset to t=0, state → 0. Top/slice/flat live 12 frames; lob/drop/smash 15.
- `.UVA` (lob, smash) is loaded as an unused 2nd clip of the MTA channel (channel 1 has no clip) and never plays: a game bug, not ported.
- impact_lob_a.MTA drives `Material #25`, which the model doesn't have; the game binds only existing names (entry counts in the capture agree).
- Impact scale (mesh+0x120): fx+0xd0 ∈ {0 top, 2 flat}: `2·sqrt(x²+y²+z²)` of the ball velocity (ball+0x140) on the first live frame, ps2 order `mul(sqrt(add(add(xx,yy),zz)),2)`; else 1.0. Bit-exact.
- Capture: tools/record_effects.py 5 (research/fx_rec.py parses it). context/fixtures/effects_s05.bin = 2279 gap-free frames (vsync 7577–9855), 22 impacts: top 8, slice 3, flat 6, lob 3, smash 2, no drop. The 9000-frame run stalled after 2279 frames (PCSX2 still running, no new vsyncs seen), so it was killed and the partial file kept.
- Test hst-sim tests/effect.rs: `impacts_s05` checks every impact frame bit for bit: three clock times, every MOR weight, every MTA alpha, live/end frame and scale. `every_effect_binds` builds all 15 effect models with key channels and runs each to its end.
- Impact world matrix (start 0x340860 → 0x328780, written once to mesh+0xe0): d = v·q with q = div(1, sqrt((x²+y²)+z²)) (FPU madd chain, this order; z-first or VU0 fail some impacts); x row = normalize(up × d) = (d.z, 0, −d.x) with the game's ×0/×1 products; y row = normalize(d × x); z row = d (w = v.w·q); x/y w = q·0. Translation = court marker 8, which is the ball position (ball+0xe0) in every capture. |d.y| ≥ 0.999999 takes a ±90° turn about x instead (not seen; approximated). Bit-exact on all 22 impacts (`impact_matrix`).
- Port: hst_sim::effect::{Effect, impact_scale, impact_matrix}. Node matrices (`locals`, via pose::Clip) aren't checked against the game yet; effect ANIs are almost static.
