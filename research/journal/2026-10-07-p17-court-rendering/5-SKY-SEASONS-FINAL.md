# P17e — court season, time of day, sky and clear colour

- Scope: which court models a match loads (season masks, SSN1), which sky draws, and the screen clear colour that shows through the sky dome's open top. Port: main.rs `load`, `layout::in_season`, `gs::court_clear`.
- Season: the court-load function takes (court, hole, season, weather) and keeps them in the court manager (+0x74/+0x78/+0x7c/+0x80). Its caller passes season = (players < 3): singles is season 1, doubles season 0. Season ≠ 0 loads `court/NN/ssnS/holHH.xb` instead of `holHH.xb`. SSN1/HOL01.XB has the same plant file as HOL01.XB; the only difference is the net model (`znet_s0100` vs `znet_s1000`). The weather argument comes from a table (P17i).
- Name parse at load: `_hNN` gives the hole. `_sXXXX` gives a 4-bit mask, with the first digit meaning season 0; a `_sky` match is skipped and the search runs again. `_wXXX` is parsed but never tested, and no file uses it. A name with `_p01` is rejected and never loaded (resort_bg_s1111_p01 and the `_clo_`/`_acc_` `_p01` models on courts 2–6 and 9).
- Category filter: hole models need the same hole and the season bit. holeend needs the same hole. bg/acc/clo/sky/cloud/tree need the season bit. The rest always load.
- Sky: every in-season sky loads, but only the first category-5 model in entry order is drawn. Court 10 loads greece00_sky_s1100 and greece01_sky_s1111 and draws greece00. Skies are uncapped cylinders (court 10: r 1800, game y −2.6 … −1452.6), untextured, with MTL colour (255,255,255,128).
- envir_cNN.dat (CMN.XB): the time-of-day threshold is an i8 at 0x10 + season·0x30. The sub-row t is 1 when the threshold is below the hole, which is always 1 in tennis. Only court 9 season 0 has threshold 0, which gives the reddish sunset light; everything else uses t 0. The light row at 0xd0 + season·0x70 + t·0x38 holds floats: RGB, intensity, ambient, then +0x14..+0x20, which go to other setters. The fog row (P17b) index is the season, not the time of day, so singles uses row 1.
- Clear colour: the per-frame env update writes an RGBAQ that the full-screen clear sprite uses.
  - Formula: clear[i] = min(255, (C[i]·L[i]·(intensity+ambient)·F + FOGCOL[i]·(255−F)) / 255), truncated.
  - C is the vertex colour × MTL colour / 128 of the sky's top-most vertex (smallest game y; on ties the last vertex wins). L is the light RGB. F is the fog row's +0x34 float.
  - F is raised by an eye-height term, clamp((−30−eye_y)·0.02, 0, 0.7), when fog row byte 1 is 0. That term is 0 for a match camera, so the port skips it (ponytail).
  - Weather 2..5 averages the light RGB and turns the fog white (P17i).
- Verification: slot 5 (court 10, doubles, season 0) RAM holds clear 0x672811. C = (7,17,43)·255/128, L = (0.863, 0.839, 0.839), 0.74 + 0.70, F 255 gives (0x11, 0x28, 0x67), an exact match (test `court_clear_colour`). Port render `context/c10d.png` clears to (17, 40, 103). Singles (`context/c10s.png`) clears to (30, 53, 108), which has no PCSX2 capture (no singles save state); it follows from the same formula with season-1 rows.
- Left as is: P17c's VU1 light (0.49 diffuse, 0.5 ambient) is a different source from this view light and is unchanged.
